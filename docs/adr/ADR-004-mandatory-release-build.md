# ADR-004: 实机安装与调试强制 Release 准则

## 上下文
智能手表（如 OPPO Watch X / X2 系列）搭载功耗敏感型穿戴芯片与小容量电池。Debug 变体包含大量未优化的 Compose 运行时调试信息、慢速反射检查及冗余日志输出，会导致在真机上滚屏掉帧、表冠防抖失真及功耗虚高，无法真实反映生产环境下的用户体验。

## 决策
对于真机测试、日常自用与公开发行，一律强制构建并安装 Release 变体（`assembleRelease` 产出的 `app-release.apk`），严禁使用 Debug 包作为实机体验与性能评估标准。

## 后果
- 正面：享受 R8 代码收缩、混淆优化与 Baseline Profile 带来的 AOT 预编译提速，确保 60fps 满帧滚动与超低待机功耗。
- 正面：安装包体积压缩至 1MB 以内，大幅减少手表闪存与 RAM 占用。
- 负面：定位线上特异性 Bug 时需依赖标准 Logcat 或特定 Crash 追踪。
