# ADR-009: 圆屏外轮廓相切弧形状态栏与两端对齐排版

## 上下文
在 466x466 圆屏智能手表中，传统水平顶部状态栏会严重侵占中间黄金阅读区域。若将电量与时间弯曲绘制在左右两侧表盘弧形边缘，如果使用居中对齐，全宽数字（如 0、8）与半宽字符（如冒号 `:`、1）的字符宽度不均会导致弧度反向塌陷，呈现波浪畸变。同时，窄屏下的正文排版若不作处理，两端边缘参差不齐。

## 决策
1. **外轮廓相切动态对齐算法**：
   - 右侧时间沿右圆周逆时针绘制，采用 `Paint.Align.RIGHT`；
   - 左侧电量沿左圆周顺时针绘制，采用 `Paint.Align.LEFT`；
   - 字符基线严格相切于手表圆形物理外边缘，字符宽度差异向屏幕内侧自由吸收，根除视觉弧度反向凹陷。
2. **两端对齐排版**：
   - 开启 Compose 正文两端平整对齐，消灭右侧锯齿状空白。
3. **几何安全区内边距**：
   - 依据圆屏几何方程严密计算阅读内接安全区，顶部保留 44~52dp、底部保留 56~64dp，防止正文与操作按钮被圆角截断。

## 后果
- 正面：表盘左右弧边呈现贴合圆环的视觉张力，时间与电量弧度圆润平滑。
- 正面：正文排版规整，全面契合手表圆形物理形态。
- 负面：方屏设备上弧形状态栏将退化为常规顶部水平布局或需配置开关。
