# ADR-005: 明确放弃手表端常驻内置 TTS 语音朗读特性

## 上下文
部分阅读类应用包含听书（TTS，Text-To-Speech 语音合成）功能。智能手表使用场景中，用户常有听书或语音朗读的泛化需求。

## 决策
明确不在 WatchReader 中引入内置 TTS 语音朗读引擎与音频常驻播放服务。

## 理由与权衡
1. **硬件与系统局限**：OPPO Watch 等穿戴系统中的内置 TTS 引擎通常音质生硬机械，若引入三方离线语音包会导致安装包体积暴增数十兆，违背 <1MB 的极简定位。
2. **功耗开销剧烈**：连续语音合成计算与常驻音频 AudioTrack 播放会导致手表面板与 CPU 持续高频运转，电池续航急剧缩短（通常不足 2 小时）。
3. **定位专注**：WatchReader 的核心定位是“极致省电、沉浸、克制的腕上微光视觉阅读器”，专注于 AMOLED 纯黑护眼与表冠机械滚屏体验。

## 后果
- 正面：维持安装包体积低于 1MB，消除音频焦点管理、后台常驻唤醒锁（WakeLock）与高功耗开销。
- 负面：无法满足部分用户“用手表外放或蓝牙耳机听书”的需求。
