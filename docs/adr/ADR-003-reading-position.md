# ADR-003: 阅读位置、书签与书架配置基于 DataStore 单事务原子持久化

## 上下文
用户在腕上阅读过程中，需要随时自动记忆阅读位置（章节、字符索引），并在再次打开时瞬间无缝恢复。同时应用需要支持书架书籍列表、置顶状态、分卷多书签记录、夜间调光与翻页速度等偏好配置的持久化。手表端频繁意外熄屏或退出时，数据写入必须具备原子性，杜绝损坏。

## 决策
1. 技术选型：全面采用 Android Jetpack DataStore（Preferences DataStore），彻底淘汰并清理旧版 `SharedPreferences`。
2. 架构模式：采用基于 Kotlin Coroutines 与 `Flow` 的单事务原子异步存取，通过 `DataStoreManager` 统一暴露响应式状态流。
3. 数据结构：书架元数据、多书签列表均采用轻量 JSON 字符串与原子键值组合存储，并支持书签增删查改与模糊搜索联动。

## 后果
- 正面：彻底根除了 SharedPreferences 在主线程同步 I/O 引起的 ANR 风险。
- 正面：单事务原子写入保证即使手表强行断电或杀死进程也不会出现数据损坏或半截写入。
- 正面：原生支持书签集合（多书签）、书籍置顶状态与多维设置项的统一响应式流动。
