# ADR-002: 章节检测使用融合正则匹配与二进制磁盘索引

## 上下文
中文网文章节格式多样，需要支持“第X章”、“第X节”、“序章”、“番外”等多种格式。超长篇大文件（数十万字至数百万字）需要毫秒级秒开与高效索引跳转，不能在每次打开书籍时全量重新正则扫描。

## 决策
1. 正则匹配：使用融合多模式正则表达式（支持序、卷、章、回、节、番外等格式）进行章节标题提取。
2. 持久化缓存：扫描完成后通过 `ChapterDiskCache` 将章节标题列表与字符起始偏移量以轻量二进制格式（`.chapters.bin`）持久化至本地私有缓存目录。
3. 演进说明：初期曾试验通过 SharedPreferences 序列化存储，后因超长章节列表导致内存膨胀与卡顿，重构为 `ChapterDiskCache` 专用二进制文件序列化，彻底消除内存抖动。

## 后果
- 正面：覆盖绝大部分中文网络小说章节格式，首次加载扫描耗时低于 1 秒。
- 正面：二次及后续打开通过二进制文件反序列化秒开（耗时 < 10ms），内存开销极低。
- 负面：正则模式覆盖偶有边缘特异格式，可随版本迭代扩充规则。
