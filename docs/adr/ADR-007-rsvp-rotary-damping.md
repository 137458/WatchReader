# ADR-007: RSVP 闪读与硬件表冠强阻尼自适应滤波算法

## 上下文
在手表小圆屏上，眼球不断上下左右扫视容易引起疲劳。RSVP（Rapid Serial Visual Presentation，快速串行视觉呈现）可将词元固定在屏幕中心逐字流出。但在调节阅读速率（WPM）时，机械表冠的高灵敏度会导致数值飞速狂飙或跳档。

## 决策
1. **ORP 黄金注视焦点**：每个词元流提取最佳注视点（ORP，汉字单字居中、词组注视第 2 字符）并以红橙色高亮，配合上下刻度微标对齐，实现眼球零位移阅读。
2. **标点权重自适应节奏**：遇到句号、感叹号、逗号或长生僻词时，自动按预设权重加乘停顿毫秒数，模拟自然呼吸节律。
3. **表冠强阻尼滤波算法**：
   - 在 Activity 顶层分发管线拦截表冠滚动事件；
   - 引入 2.5 档物理门限与 120ms 时间窗口节流；
   - 将连续微小刻度聚合为扎实的步进跳变，并联动线性马达提供齿轮阻尼感。
4. **手势快退/快进辅助**：支持屏幕水平滑动手势，实现按词元步退或步进。

## 后果
- 正面：阅读效率提升 2~3 倍，视疲劳显著降低。
- 正面：表冠调速稳健顺手，彻底杜绝轻触表冠导致数值狂飙的偶发问题。
- 负面：部分习惯一目十行扫读的用户需要一定时间建立闪读注视习惯。
