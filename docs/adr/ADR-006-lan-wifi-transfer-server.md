# ADR-006: 局域网轻量无线传书与流式直存架构

## 上下文
智能手表与手机或电脑之间通常缺乏标准 USB 数据线直连传输方式，或者受限于蓝牙小带宽（传输一本数十兆长篇小说耗时过长）。用户急需一种简单、免装外部 App、跨平台的传书方案。

## 决策
1. **内置轻量 HTTP 服务**：手表端集成基于原生 Socket 实现的非侵入式轻量 HTTP 服务器（NanoHTTPD 架构设计），运行在 8080 端口。
2. **免 App 浏览器交互**：同 Wi-Fi 局域网下，用户在手机或 PC 浏览器打开手表显示的 IP 网址即可拖拽上传 TXT/EPUB 文件。
3. **分块流式落盘**：文件传输采用边解析 Multipart 边写入私有文件的流式落盘机制，避免全量缓冲至内存造成 OOM。
4. **单事务刷新书架**：文件接收完毕后，自动解构元数据并触发 DataStore 单事务原子追加，即时更新书架。

## 后果
- 正面：传输速率达 5MB/s~10MB/s，数十兆大文件数秒即可传输完毕。
- 正面：用户侧零依赖，无需安装任何专用传输 App 或驱动。
- 负面：传输时手表必须与上传设备处于同一 Wi-Fi 局域网。
