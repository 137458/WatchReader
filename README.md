# WatchReader

WatchReader 是一款专为智能手表（Android / Wear OS 圆屏设备，如 OPPO Watch X / X2 等）深度定制的极简本地电子书阅读器，原生支持 TXT 与 EPUB 双格式。

基于 Jetpack Compose 构建，针对可穿戴小圆屏场景与物理旋转表冠交互进行深度优化，提供克制沉浸、高帧率平滑、超低功耗的腕上阅读体验。

## 核心特性

- **TXT / EPUB 双格式高性能引擎**：
  - **EPUB 架构**：采用单趟流式索引与随机访问双引擎架构，精准抽取 NCX、Nav 目录与 Spine 线性阅读顺序；内置正文 LRU 页面缓存池，实现大文件多章节毫秒级即时加载与无缝翻章。
  - **TXT 架构**：内置 GBK 与 UTF-8 编码自动识别算法，采用基于字符索引的高效分块切片，十万字长篇小说瞬间秒开。
- **局域网 Wi-Fi 网页无线传书**：
  - 内置轻量 HTTP 文件服务，无需连接数据线或依赖外部手机配套 App。
  - 手表端点击传书开启服务后，同一 Wi-Fi 局域网内的手机或电脑浏览器访问指定 IP 网址即可批量拖拽上传 TXT/EPUB 电子书，支持实时传输进度指示并在完成后即时入库书架。
- **RSVP 动态单行闪读（快速串行视觉呈现）**：
  - 表盘中央大字号清晰呈现词元流，配合 ORP（Optimal Recognition Point，最佳注视识别点）黄金焦点醒目高亮与视线对齐微标，视线无需左右往复扫描即可快速汲取信息。
  - **智能节奏控制**：遇到逗号、句号、感叹号、问号及长词时按权重自适应延长驻留毫秒数，大幅缓解视觉疲劳。
  - **多元速度交互**：支持物理表冠旋转无级微调阅读速率（WPM）、触屏多档位快捷切换，以及左右滑动手势微步回退与快进。
- **圆屏工程美学与相切贴边状态栏**：
  - **外轮廓相切对齐状态栏**：电量与时间分别沿圆形表盘左右外轮廓弧度动态相切对齐（左侧电量左对齐，右侧时间右对齐），精准贴合圆屏物理边框，根除全宽数字与窄字符引起的弧度反向塌陷与视觉畸变。
  - **内接安全区与两端对齐排版**：基于圆屏几何模型严密计算文本内接安全区，结合两端对齐算法，消除上下与左右边缘截字，保证正文段落边缘平整统一。
- **物理旋转表冠与线性马达触觉反馈**：
  - 底层拦截原生表冠旋转事件，结合自适应刻度累加器与防抖滤波算法，映射为高帧率平滑滚屏，阻尼感扎实平稳。
  - 深度联动线性马达，在表冠转动与翻章时提供细腻真实的机械刻度触觉反馈。
- **双轨极暗调光与 AMOLED 纯黑省电**：
  - 专为夜读与暗光环境设计独立双轨调光系统（应用内独立亮度调节与纯黑暗度遮罩），突破系统级最低亮度阈值，提供 1% 至 100% 极暗微光护眼显示。
  - 全界面纯黑底色结合低功耗渲染，深度发挥 AMOLED 屏幕像素级自发光省电优势。
- **书架与书签管理**：
  - 支持即时模糊搜索过滤小说，支持常用书籍一键置顶与格式胶囊徽章显示。
  - 内置两段式防误触删除与自动超时恢复机制，避免手表小屏误触抹除书籍。
  - 快捷菜单一键存取书签，目录界面支持“目录 / 书签”双 Tab 切换与秒级定位跳转。
  - 基于 Jetpack DataStore 的全异步响应式存储，精准记录每本书的章节与精确字符阅读进度。
- **极致轻量与高兼容性**：
  - 纯原生 Compose 架构，编译产物极度精简（不到 1MB），冷启动迅速，内存占用极低，无后台常驻冗余唤醒。

## 下载与安装

请前往 [Releases](../../releases) 页面下载最新版本的 `app-release.apk`。

### 安装方法

1. **通过 ADB 命令行安装（推荐）**：
   ```bash
   adb install -r app-release.apk
   ```
2. **通过手表工具箱 / 腕上应用助手安装**：
   将下载的 APK 文件通过手机端手表配套管理工具或第三方手表工具箱无线推送到手表端完成安装。

## 系统与设备要求

- **操作系统**：Android 8.1 (API 27) 及以上版本系统。
- **适用设备**：搭载 Android / Wear OS 系统的圆屏与方屏智能手表（如 OPPO Watch X / X2 系列、小米手表、TicWatch 等）。
- **推荐屏幕**：466x466 分辨率及以上 AMOLED 圆形屏幕。

## 操作与交互指引

| 界面 / 场景 | 操作方式 | 功能说明 |
| :--- | :--- | :--- |
| **书架** | 点击顶部“传书” | 开启局域网 Wi-Fi 传书服务，显示网页上传地址 |
| **书架** | 点击搜索图标 | 展开即时搜索框，支持书名拼音/文字模糊筛选 |
| **书架** | 点击“置顶 / 取消置顶” | 将常用书籍固定在书架顶部 |
| **书架** | 点击“删除书籍” | 触发防误触保护，需在 3 秒内再次点击确认删除 |
| **阅读正文** | 旋转物理表冠 | 触发带触觉震动的平滑上下滚屏 |
| **阅读正文** | 双击屏幕 | 开启或暂停自动平滑滚屏 |
| **阅读正文** | 长按屏幕 | 呼出功能菜单（调速、字号、双轨亮度、书签、目录等） |
| **闪读模式** | 旋转物理表冠 | 无级微调阅读速率（每分钟字数 WPM） |
| **闪读模式** | 单击屏幕中央 | 暂停或继续单行闪读词元流 |
| **闪读模式** | 左右快速滑动 | 以词元为单位向前回退或向后快进 |
| **目录 / 书签** | 顶部 Tab 切换 | 在全书章节树与已保存书签列表之间无缝切换 |

## 源码编译（面向开发者）

### 环境要求

- JDK 17 及以上
- Android SDK 34
- Gradle 8.2+

### 编译步骤

```bash
# 编译 Release APK
./gradlew assembleRelease

# 安装到已连接的调试设备
./gradlew installRelease
```

编译产物路径位于：`app/build/outputs/apk/release/app-release.apk`。
