# WatchReader

WatchReader 是一款专为智能手表（Android / Wear OS 圆屏设备，如 OPPO Watch X / X2 等）深度定制的极简本地电子书阅读器，全面支持 TXT 与 EPUB 格式。

基于 Jetpack Compose 构建，针对智能手表的小圆屏阅读场景与表冠交互进行了专门优化，提供丝滑、沉浸且省电的腕上阅读体验。

## 特性

- **多格式本地电子书解析**：支持本地 TXT 与 EPUB（.epub）格式。内置毫秒级双引擎架构（随机访问与单趟流式索引）与 GBK/UTF-8 编码自动识别。
- **局域网 Wi-Fi 网页无线传书**：内置轻量 HTTP 传书服务，手机或电脑浏览器输入网址即可批量拖拽上传 TXT/EPUB 电子书，支持实时传输进度并在传输完成后即时同步至书架。
- **RSVP 动态单行速读（闪读模式）**：表盘中央大字号呈现词元流，按标点自动调节停顿节奏，支持物理表冠旋转高精度线性调速与触屏档位切换。
- **书签管理与目录双 Tab 快速回溯**：在菜单中一键标记关键段落，在目录页可切换书签列表秒级跳转或删除。
- **书架即时搜索与书籍置顶**：支持小说标题即时模糊筛选过滤，支持常用小说置顶与格式徽章显示。
- **圆屏专属安全区适配**：智能计算圆屏内接显示区域（SafeArea），消除正文与操作栏被手表弧形边缘截断或遮挡的问题。
- **物理旋转表冠平滑滚动**：拦截原生表冠滚动事件并映射为高帧率平滑滚屏，配合线性马达触觉反馈（Haptic Feedback），提供真实的机械刻度阻尼感。
- **自动滚屏与调速**：内置自动阅读引擎，支持精准像素级平滑平移，可在设置菜单中实时调整滚屏速率。
- **智能章节检测与预热缓存**：TXT 采用融合正则分块索引，EPUB 采用高效 NCX/Nav 导航目录提取与正文 LRU 缓存池，秒开大文件并实现 0ms 翻章。
- **断点记忆与书架管理**：基于 DataStore 进行异步响应式状态存储，自动记录每本书的章节与精确字符阅读进度。
- **AMOLED 纯黑省电与暗色模式**：默认纯黑背景配合低功耗渲染，支持字号无级调节与应用内独立屏幕亮度控制。
- **定制自适应应用图标**：内置专为手表屏幕设计的高清自适应应用图标与圆形图标。
- **极致精简与高兼容性**：基于标准 Compose 架构开发，安装包体积不到 1MB，内存占用极低。

## 下载与安装

请前往 [Releases](../../releases) 页面下载最新版本的 `app-release.apk`。

### 安装方法

1. **通过 Wi-Fi 传书直接导入书籍（推荐）**：
   在手表端打开应用并点击顶部“传书”，在手机或电脑浏览器中输入手表显示的 IP 网址即可批量拖拽上传。
2. **通过 ADB 命令行安装**：
   ```bash
   adb install -r app-release.apk
   ```
3. **通过手表工具箱 / 腕上应用助手安装**：
   将下载好的 APK 文件通过手机端配套应用或第三方手表管理工具推送到手表端完成安装。

## 系统要求

- **操作系统**：Android 8.1 (API 27) 及以上版本系统。
- **推荐设备**：OPPO Watch 系列（OPPO Watch X、X2 等）、小米手表、TicWatch 以及其他搭载 Android / Wear OS 系统的圆屏或方屏手表。
- **屏幕推荐**：466x466 分辨率及以上 AMOLED 屏幕。

## 使用说明

1. **导入书籍**：
   - 点击书架顶部“传书”通过 Wi-Fi 局域网从手机或电脑上传。
   - 或点击“+ 导入”通过系统文件选择器选择存储在手表中的 `.txt` 或 `.epub` 文件。
2. **阅读交互**：
   - **旋转表冠**：平滑上下滚动阅读文本；在闪读模式下微调阅读速度。
   - **长按正文**：呼出设置与导航菜单。
   - **双击屏幕**：开启或暂停自动平滑滚屏。
3. **设置调节**：
   - 在快捷菜单中可快速调节字体大小、暗色/明亮模式切换、滚屏速度、存为书签、切换闪读速读以及屏幕亮度。

## 源码编译（面向开发者）

### 环境要求

- JDK 17 及以上
- Android SDK 34
- Gradle 8.2+

### 编译步骤

```bash
# 编译 Release APK
./gradlew assembleRelease

# 安装到已连接的调试设备
./gradlew installRelease
```

编译产物位于 `app/build/outputs/apk/release/app-release.apk`。
