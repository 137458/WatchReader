# WatchReader

WatchReader 是一款面向智能手表的本地电子书阅读器，针对 Android / Wear OS 圆屏设备（如 OPPO Watch X / X2）的 466x466 屏幕与物理旋转表冠设计。纯 Jetpack Compose 实现，格式解析仅使用平台标准库，不引入第三方解析依赖；Release APK 约 1.1 MB，无后台常驻。

## 支持格式

| 格式 | 扩展名 | 说明 |
| :--- | :--- | :--- |
| TXT | `.txt` `.md` `.log` | UTF-8 / UTF-16 / GB18030 编码自动识别，流式章节索引，峰值内存 < 64 KB |
| EPUB | `.epub` | ZipFile 随机访问与单趟流式双引擎，解析 NCX / EPUB3 Nav / Spine 目录，32 章正文 LRU 缓存 |
| MOBI / AZW3 | `.mobi` `.azw3` `.azw` `.prc` | 零依赖复刻 PalmDOC 解压与容器解析，逐记录流式解压；不支持 DRM 加密与 HUFF/CDIC 压缩文件（明确报错） |
| FB2 | `.fb2` | XML 单趟流式解析，跳过元数据、封面二进制与 notes 本体 |
| HTML | `.html` `.htm` `.xhtml` | 流式标签剥离；编码探测顺序为 BOM → meta charset → UTF-8/GB18030 启发式 |

MOBI / FB2 / HTML 在首次打开时单趟流式转换为 UTF-8 文本缓存（转换期常驻内存与 TXT 扫描同级），此后章节索引、超长章节封顶与分块读取完全复用 TXT 流式内核；二次打开零转换。转换具有确定性，缓存被系统清理后重建不改变字符偏移，阅读进度与书签保持有效。

## 功能

**阅读引擎**

- 章节融合正则检测（中英文网文章节），无标题文本按自然段生成虚拟分节。
- 超长章节按自然段边界封顶 4000 字并切分为「原标题 · n/m」续节，避免长章节冻结。
- 章节索引经二进制磁盘缓存（`ChapterDiskCache`）持久化，二次打开毫秒级进入。

**交互**

- 物理表冠滚屏：表冠事件由 Activity 顶层管线拦截，经极性归一化与强阻尼滤波（物理门限 + 时间窗口节流），联动线性马达刻度触觉。
- 点按翻页：上下分屏 / 左右分屏 / 关闭三种分区模式，翻页保留视觉锚点行。
- 自动平滑滚屏：速度在菜单中调节，滚屏中单击任意位置暂停；关闭点按分区时中央单击切换开关。
- 弧形寻道：沿表盘弧边拖动滑块实时预览目标章节与百分比，松手跳转。
- 阅读页底部微光进度指示，操作时自动避让。

**RSVP 闪读**

- 表盘中央词元流呈现，ORP 最佳注视点高亮与视线对齐微标。
- 按标点与词长加权自适应驻留时长。
- 表冠无级调速（WPM），左右滑动按词元回退 / 快进。

**排版与外观**

- 排版净化开关：开启态压缩空行、剥离冗余空白并补全角缩进；关闭态保留源文件换行、空行与缩进。两态独立缓存，切换即时生效。
- 正文两端对齐，圆屏内接安全区计算，消除边缘截字。
- 字号 10–24 连续调节；黑体与系统 CJK 宋体切换（应用侧解析系统字面，不内置字体文件）。
- 三套主题：羊皮纸浅色、极光深色、纯黑深红夜视（AMOLED）。
- 双轨调光：应用内独立亮度叠加纯黑暗度遮罩，可低于系统最低亮度。

**书架与数据**

- 即时搜索、置顶、两段式防误触删除（超时自动恢复）。
- 书签保存与定位跳转；目录 / 书签双 Tab 秒级切换。
- 阅读进度按字符偏移经 DataStore 单事务原子持久化；有效阅读时长统计。

**Wi-Fi 传书**

- 内置轻量 HTTP 服务（NanoHTTPD 原生 Socket），手机 / 电脑浏览器访问指定地址即可批量上传，支持分块流式直存与实时进度，上传完成原子刷新书架。
- 网页端可查看手表书架并删除、下载书籍；支持高对比度二维码扫码直连。

## 下载与安装

前往 [Releases](https://github.com/137458/WatchReader/releases) 页面下载最新版本的 `app-release.apk`。

1. ADB 安装：

   ```bash
   adb install -r app-release.apk
   ```

2. 或经手机端手表管理工具 / 第三方手表工具箱将 APK 推送到手表安装。

## 系统与设备要求

- Android 8.1（API 27）及以上。
- 搭载 Android / Wear OS 的圆屏或方屏智能手表（OPPO Watch X / X2 系列、小米手表、TicWatch 等）。
- 推荐 466x466 AMOLED 圆形屏幕；界面按圆屏内接安全区设计。

## 操作与交互

| 界面 / 场景 | 操作方式 | 功能说明 |
| :--- | :--- | :--- |
| 书架 | 点击「传书」 | 开启 Wi-Fi 传书服务，显示网址与二维码 |
| 书架 | 点击搜索图标 | 展开搜索框，按书名即时筛选 |
| 书架 | 点击书籍卡片上的置顶 / 删除 | 置顶排序；删除需 3 秒内二次确认 |
| 阅读 | 旋转表冠 | 带触觉反馈的平滑滚屏 |
| 阅读 | 单击上 / 下分区 | 翻页（分区模式可在菜单中切换为上下 / 左右 / 关闭） |
| 阅读 | 单击中央区域 | 呼出功能菜单；关闭点按分区时为自动滚屏开关 |
| 阅读 | 长按 | 呼出功能菜单 |
| 阅读 | 自动滚屏中单击 | 暂停 / 继续滚屏 |
| 阅读 | 拖动侧边弧形滑块 | 实时预览并跳转章节与百分比 |
| 菜单 | 长按或单击中央呼出 | 调速、字号、亮度、主题、字体、排版净化、书签、目录、闪读入口 |
| 闪读 | 旋转表冠 | 无级调节阅读速率（WPM） |
| 闪读 | 单击 | 暂停 / 继续 |
| 闪读 | 左右滑动 | 按词元回退 / 快进 |
| 目录 / 书签 | 顶部 Tab 切换 | 章节树与书签列表互切，点击即定位 |

## 源码编译（面向开发者）

### 环境要求

- JDK 17 及以上
- Android SDK 34
- Gradle 8.2+

### 编译与测试

```bash
# 编译 Release APK
./gradlew assembleRelease

# 安装到已连接设备（Release 变体）
./gradlew installRelease

# 运行单元测试
./gradlew testDebugUnitTest
```

编译产物路径：`app/build/outputs/apk/release/app-release.apk`。
